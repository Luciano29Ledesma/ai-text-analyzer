# AI Text Analyzer API

API desarrollada con Python y FastAPI que permite analizar textos utilizando un modelo de inteligencia artificial ejecutado localmente mediante Ollama.

## Funcionalidades

 Recibir textos mediante una API REST.
Analizar el sentimiento del texto.
 Generar un resumen breve.
 Identificar temas principales.
Devolver los resultados en formato JSON.
Utilizar un modelo de IA local sin depender de una API paga.

## Tecnologías utilizadas

 Python
 FastAPI
 Pydantic
  Ollama
Llama 3.2
Uvicorn
